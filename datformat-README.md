# Raytracer scene file format

This document defines the plain-text scene file format used by `robot.dat`,
`ele.dat`, and `dragon.dat`.

## Character encoding and lexical rules

Scene files are ASCII text.

Whitespace separates tokens and has no semantic meaning. Records may span
multiple lines. The format has no comments, object names, string fields, include
directives, or stored image dimensions.

Numbers use decimal C syntax as accepted by `strtod`. The supplied files use
forms such as:

```text
35
4.
.7
1.
-0.5
2.15
```

Integer fields are base-10.

## Value forms

The format uses three bracketed value forms.

Vector:

```text
(x,y,z)
```

Angle pair:

```text
[altitude,azimuth]
```

Color:

```text
<red,green,blue>
```

Vector components are renderer-space coordinates. Angle components are degrees.
Color components are renderer-space floating-point values. Color values are not
limited to the range `0.0` through `1.0`; the supplied ground colors include
values such as `<1.5,1.,0>`.

## Top-level structure

A scene file contains the following records in order:

```text
observer
view_angles
focal_scale
object_list
lamp_count
lamp_list
environment
```

The file does not store output width, output height, sampling level, palette
state, or output format.

## Observer

The observer record is a vector:

```text
(x,y,z)
```

It defines the camera position in renderer space.

Known values:

```text
robot.dat   (-10,-4,5.5)
ele.dat     (0,-22,3)
dragon.dat  (-22,-44,11)
```

## View angles

The view-angle record is an angle pair:

```text
[altitude,azimuth]
```

The renderer converts both values from degrees to radians before constructing
the view basis.

Known values:

```text
robot.dat   [-10,20]
ele.dat     [13,61]
dragon.dat  [9,61]
```

## Focal scale

The focal-scale record is a single number:

```text
focal_scale
```

The renderer multiplies this value by `0.028` to produce its internal focal
length.

Known values:

```text
robot.dat   35
ele.dat     28
dragon.dat  28
```

## Object list

The object list follows the focal scale. Each object defines one or more
spheres. All spheres generated by one object share the same color and material.

Object form:

```text
<red,green,blue> material sphere_point segment* ;
```

Sphere point form:

```text
(x,y,z):radius
```

The first sphere point creates one sphere directly. Each following segment
generates additional spheres by interpolation.

The object list ends with a standalone semicolon after the final object:

```text
;
```

Since every object also ends with a semicolon, the last object may be followed by
two semicolons:

```text
... (x,y,z):radius;;
```

The first semicolon terminates the object. The second semicolon terminates the
object list.

## Materials

The material field is an integer.

Known material values:

```text
0  diffuse surface
1  diffuse surface with bright highlight handling
2  mirror surface
```

No other material values are present in `robot.dat`, `ele.dat`, or `dragon.dat`.

## Sphere interpolation

A segment has this logical form:

```text
count sphere_point
```

The `count` token follows the previous sphere point and precedes the next sphere
point. In the supplied files it may appear at the end of the previous line:

```text
(-5,4.5,16):0.5      10
(-8,3,14):0.7        5
```

This represents one segment from `(-5,4.5,16):0.5` to `(-8,3,14):0.7` with
`count = 10`, followed by another segment whose count is `5`.

For a segment with `count = n`, the segment adds `n + 1` generated spheres. The
previous control point is not duplicated. The next control point is included as
the final generated sphere.

Generated spheres use indices `i = 1` through `n + 1`:

```text
t        = i / (n + 1)
position = previous_position + (next_position - previous_position) * t
radius   = previous_radius   + (next_radius   - previous_radius)   * t
```

Example:

```text
<1,.1,.1> 1 (0,0,4.6):0.8 5 (0,0,3.3):0.6;
```

This object creates one initial sphere and six generated spheres. The final
generated sphere is exactly `(0,0,3.3):0.6`.

## Lamps

The object list is followed by the lamp count:

```text
lamp_count
```

Each lamp record is a sphere point followed by a color:

```text
(x,y,z):radius <red,green,blue>
```

The radius is part of the lamp record.

Known lamp records:

```text
robot.dat   (-100,50,150):15   <1,1,1>
ele.dat     (-15,-50,40):15    <1,1,1>
dragon.dat  (-45,-150,120):15  <1,1,1>
```

All three known scene files contain one lamp.

## Environment

The environment record contains five colors:

```text
<ground_0> <ground_1> <ambient> <sky_zenith> <sky_horizon>
```

`ground_0` and `ground_1` define the checkerboard ground colors. `ambient`
defines the ambient illumination color. `sky_zenith` and `sky_horizon` define
the vertical sky gradient. In the known scenes, the horizon color is the lighter
sky color.

Known environment records:

```text
robot.dat   <1.5,1.5,0> <0,1.5,0>   <.25,.25,.25> <.1,.1,1> <.7,.7,1>
ele.dat     <1.5,1.,0>  <1.5,1.,0>  <.25,.25,.25> <.1,.1,1> <.7,.7,1>
dragon.dat  <1.5,1.,0>  <1.5,1.,0>  <.25,.25,.25> <.1,.1,1> <.7,.7,1>
```

## Known scene inventory

Sphere counts include spheres generated by interpolation.

```text
robot.dat   13 objects,  9 segments,  79 spheres, 1 lamp
ele.dat     10 objects, 19 segments, 120 spheres, 1 lamp
dragon.dat  21 objects, 49 segments, 288 spheres, 1 lamp
```

## Grammar

```text
scene          ::= observer view_angles focal_scale object_list lamps environment

observer       ::= vector
view_angles    ::= "[" number "," number "]"
focal_scale    ::= number

object_list    ::= object* ";"
object         ::= color material sphere_point segment* ";"
material       ::= integer
segment        ::= integer sphere_point
sphere_point   ::= vector ":" number

lamps          ::= integer lamp*
lamp           ::= sphere_point color

environment    ::= color color color color color

vector         ::= "(" number "," number "," number ")"
color          ::= "<" number "," number "," number ">"
number         ::= decimal floating-point value
integer        ::= decimal integer value
```

The integer at the start of `lamps` is the number of following `lamp` records.

## Compatibility limits

The known format contains only spheres, interpolated sphere chains, lamps,
checkerboard ground colors, ambient light, and sky colors. A compatible reader
for `robot.dat`, `ele.dat`, and `dragon.dat` does not need to support comments,
named objects, alternate primitive types, textures, transformation records,
expanded material records, stored image dimensions, or external file references.
